# Admin Panel for Dholasan Community Website

A comprehensive admin panel that lets you manage **all content** on your Dholasan Community Website without touching code. The admin panel is located at `/#/admin` protected by a login, with a dashboard UI and live visual inline editing.

## Background & Architecture
Your website is a **React + TypeScript + Vite + Tailwind CSS** app inside `Dholasan-Community-Website-2/`.

### Core Capabilities:
- **News Articles**: Full CRUD, bilingual English & Gujarati.
- **Events & Festivals**: Full CRUD with past/upcoming toggling.
- **Gallery Images**: Categorized photo gallery with instant preview.
- **Businesses Directory**: Local commerce directory with phone & contact person.
- **Community Notices & Emergency Helplines**: Urgent alerts, pin-to-top, water timing, hospital numbers.
- **Live Event Broadcast**: YouTube live stream embedding with live status ticker.
- **Visual Live Preview & Click-to-Edit**: Edit any section directly from the live public site with real-time feedback.
- **Theme & Brand Customization**: Saffron primary and slate/navy secondary customizable theme colors.
- **Cloud & Local Persistence**: Instant localStorage sync and optional Firebase Firestore integration.
